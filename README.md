# ربات پرونده بیماران

آرشیو عکس برگه‌های ویزیت، آزمایش و نسخه برای هر بیمار، با جستجو و خروجی PDF.

## راه‌اندازی

1. در تلگرام از `@BotFather` یک ربات بسازید و توکن بگیرید.
2. فایل `.env.example` را به `.env` کپی کنید و `BOT_TOKEN` را پر کنید.
3. نصب و اجرا:

```bash
pip install -r requirements.txt
```

```bash
python bot.py
```

4. دکتر به ربات `/start` بدهد. ربات شناسه عددی او را نشان می‌دهد. آن را در `ALLOWED_USER_IDS` بگذارید و ربات را دوباره اجرا کنید.

## نصب روی سرور (سرویس دائمی)

روی سرور اوبونتو یا دبیان، داخل پوشه پروژه:

```bash
sudo bash install.sh
```

اسکریپت توکن را می‌پرسد، ربات را نصب می‌کند و با روشن شدن سرور خودکار بالا می‌آورد.
بعد از تغییر `.env`:

```bash
sudo systemctl restart doctor-bot
```

## استفاده

- **بیمار جدید:** دکمه «بیمار جدید»، سپس نام و موبایل.
- **جستجو:** نام، بخشی از موبایل یا شماره پرونده را بفرستید.
- **افزودن عکس:** روی کارت بیمار «افزودن عکس»، نوع برگه، سپس عکس‌ها.
- **دیدن پرونده:** «نمایش پرونده» یا «PDF».

## داده‌ها

همه چیز در پوشه `DATA_DIR` است: `patients.db` و `files/`. برای بکاپ همین پوشه را کپی کنید.
